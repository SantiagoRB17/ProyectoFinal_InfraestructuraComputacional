## 📘 Descripción general

Este proyecto corresponde al **trabajo final del curso de Infraestructura Computacional**, cuyo objetivo es **integrar conceptos de almacenamiento, virtualización y contenedores** en un entorno de servidor Linux configurado desde cero.

El proyecto se desarrolla sobre una máquina virtual Ubuntu Server 24.04.3 LTS en VirtualBox, implementando las siguientes capas tecnológicas:

1. **Gestión de almacenamiento físico y lógico** mediante RAID y LVM.  
2. **Creación y despliegue de contenedores Docker y Podman**, simulando entornos de servicios web (Apache, MySQL y Nginx).  
3. **Administración del sistema** con usuarios, permisos, red y monitoreo.  
4. **Documentación técnica completa** a través de bitácoras y evidencias.

---

## 🧩 Objetivos del proyecto

1. **Diseñar e implementar** un entorno virtualizado con Ubuntu Server.  
2. **Configurar múltiples discos virtuales** para almacenamiento redundante con RAID 1.  
3. **Gestionar volúmenes lógicos** mediante LVM para mayor flexibilidad.  
4. **Desplegar servicios en contenedores** utilizando Docker y Podman.  
5. **Documentar cada proceso** con bitácoras técnicas y evidencias gráficas.

---

## 🧠 Conceptos aplicados

- **Virtualización:** creación de entornos aislados mediante VirtualBox.  
- **Gestión de almacenamiento:** configuración de RAIDs y LVM.  
- **Contenedorización:** despliegue de aplicaciones mediante Docker.
- **Administración de sistemas Linux:** configuración, actualización y mantenimiento.
